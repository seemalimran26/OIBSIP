# xLander – Landing Page

xLander is a modern and responsive landing page designed for makers and small teams. The website presents a clean product-style interface with sections for features, workflow, pricing, and contact information.

## Features

* Responsive navigation bar
* Mobile-friendly CSS-only hamburger menu
* Hero section with call-to-action buttons
* Features section with Font Awesome icons
* Three-step "How It Works" section
* Pricing section with Starter and Pro plans
* Contact and social media footer
* Smooth scrolling navigation
* Hover effects and interactive UI elements
* Responsive layout for desktop, tablet, and mobile screens

## Technologies Used

* HTML5
* CSS3
* Google Fonts

  * Fraunces
  * Inter
* Font Awesome 6

## Responsive Design

The website is designed to work across different screen sizes using CSS media queries.

The layout adapts for:

* Desktop
* Tablet
* Mobile

The mobile navigation uses a CSS-only menu toggle without JavaScript.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation or dependencies are required.
