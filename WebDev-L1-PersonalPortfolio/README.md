# Seemal Imran — Portfolio Website

A responsive personal portfolio website showcasing my skills, projects, education, and web development experience. The portfolio is designed with a modern dark interface and highlights my work with Laravel, PHP, MySQL, JavaScript, and modern frontend technologies.

## Features

* Responsive personal portfolio design
* Modern dark-themed UI
* Fixed navigation bar with scroll effect
* Responsive mobile hamburger menu
* Smooth section navigation
* Animated typewriter text in the hero section
* Scroll reveal animations
* Responsive profile image section
* About section with developer information
* Skills and technology stack section
* Featured project section
* Project cards with GitHub repository links
* Education and learning timeline
* Contact section with email and availability information
* Contact form validation using JavaScript
* Success message after valid form submission
* Dynamic copyright year
* Reduced-motion support for accessibility

## Contact Form

The contact form includes fields for:

* Name
* Email
* Message

JavaScript validates the required fields and checks the email format before displaying a success message.

The form currently performs **client-side validation only**; it does not send the submitted message to a backend or email service.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, `script.js`, and the `images` folder are in the correct locations.
4. Open `index.html` in a web browser.

No backend server or database setup is required to view the portfolio website.
